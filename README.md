\# Canada Rental



A full-stack rental property management web application developed using ASP.NET Core MVC.



\## Overview



Canada Rental allows users to browse rental listings, manage properties, and interact with the platform through a modern web interface. The project follows the MVC architecture and was developed as a collaborative software engineering project.



\## Features



\- User authentication and authorization

\- Property listing management

\- Responsive user interface

\- Session-based login

\- Database integration

\- CRUD operations

\- MVC architecture



\## Technology Stack



\### Backend



\- ASP.NET Core MVC

\- C#

\- Entity Framework Core



\### Frontend



\- HTML5

\- CSS3

\- Bootstrap

\- JavaScript



\### Database



\- SQL Server

\## Getting Started



\### Prerequisites



\- .NET 8 SDK

\- Visual Studio 2022 or Visual Studio Code

\- SQL Server



\### Installation



```bash

git clone https://github.com/CanadaRental/Canada-Rental.git

cd Canada-Rental

dotnet restore

dotnet build

dotnet run

```
